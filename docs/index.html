遊び方とルール

  • ドット同士を線で結び、全体で交差のない1つの大きな輪（ループ）を作ります。
  • マスの中の数字は、その周囲4辺のうち線が引かれる本数を表します。
  • 「線が通らない箇所」には、目印として「×」印を置くことができます。
  • 【PCでの操作】
    ・左ドラッグ：線を描画
    ・右ドラッグ：×印を描画
    ・ホイール回転：拡大・縮小
    ・中ボタンドラッグ：スクロール移動
    ・Ctrl + Z 戻す / Ctrl + Y 進む
  • 【スマホでの操作】
    ・タップ：辺の状態切り替え
    ・長押しスライド：連続描画
    ・1本指スライド：スクロール移動
    ・2本指ピンチ：拡大・縮小
